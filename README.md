# StashBook

Automated system for digital asset aggregation and deal tracking

## Architecture
The system consists of two distinct components:

1. Backend: Go engine handles data collection, storage, and API services
2. Frontend: React application handles asset display and user interaction

## Technical Stack
- Backend: Go, SQLite
- Frontend: React, Vite, Tailwind CSS  

## Installation

### Backend
1. Navigate to the backend directory
2. Execute the engine:
   ```bash
   go run main.go
